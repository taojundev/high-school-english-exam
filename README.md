# 沪考英语 · 模拟场

面向上海高考英语的随机组卷模拟考试 Web 应用。按题型从题库抽题生成完整试卷，限时作答，交卷后自动批改，并根据失分标签与用时给出可执行的提分建议。

> 这是一个练习工具，不是官方考试系统。翻译、概要、写作使用规则模型进行自动初评，结果不能替代人工阅卷。

## 功能

- **8 大题型，314 道小题**：听力、语法、词汇、完形、阅读、翻译、概要、写作。
- **随机组卷**：每次按题型配额抽题，优先避开最近做过的题；选项顺序重新洗牌，同一套卷可复现（种子）。
- **全真 / 专项两种模式**：全卷 150 分、120 分钟；专项只练一个题型。
- **单项测试**：5 个客观题板块一题一屏，作答后才能「查看答案」，即时给出对错、标准答案、解析与按考点的指导意见；每套记录正确率与用时，独立保存，不计入成绩记录与评级。
- **限时考试**：倒计时、自动交卷、答题卡、题目标记、自动保存与断点续考。
- **听力播放**：使用浏览器英文语音合成，支持重播与原文兜底。
- **自动批改**：客观题按标准答案判分；翻译按关键信息覆盖；概要/写作按要点、词数、语言与结构进行可解释初评。
- **提分建议**：按板块正确率、考点标签与时间分配生成优先级行动清单，可直接跳转专项训练。
- **逐题复盘**：定位原文、查看正确答案、解析、关键信息覆盖与参考译文/范文。
- **成绩记录**：历次得分率趋势、板块表现、删除与清空记录。
- **题库浏览**：按题型搜索、展开答案与解析。
- **响应式与打印**：手机可用，成绩单可打印/导出 PDF。
- **本地优先**：无需注册和后端，所有数据保存在浏览器 localStorage。

## 快速开始

```bash
npm install
npm run dev
```

打开终端提示的地址（默认 `http://localhost:5173`）。

生产构建：

```bash
npm run build
npm run preview
```

`dist/` 是静态站点，可部署到任意静态托管（GitHub Pages、Netlify、Vercel、Nginx 等）。项目使用 HashRouter，刷新子页面不需要服务器重写规则。

## 试卷结构

| 板块 | 题量 | 分值 | 建议用时 | 考查重点 |
| --- | --- | --- | --- | --- |
| 听力理解 | 10 短对话 + 2 组长材料（6 题） | 25 | 20 分钟 | 细节、数字、时间、地点、原因、态度、推断 |
| 语法与词汇 | 6 单选 + 4 填空 | 10 | 8 分钟 | 时态、非谓语、从句、虚拟、倒装、主谓一致、词形 |
| 选词填空 | 10 空（11 词选 10） | 10 | 8 分钟 | 词义辨析、固定搭配、语境判断 |
| 完形填空 | 1 篇 × 15 空 | 15 | 10 分钟 | 上下文、逻辑、搭配、情感线 |
| 阅读理解 | 4 篇 × 5 题 | 40 | 28 分钟 | 细节、主旨、推断、词义、态度 |
| 翻译 | 5 句 | 15 | 10 分钟 | 主干、时态、语态、非谓语、句式、搭配 |
| 概要写作 | 1 篇（约 60 词） | 10 | 12 分钟 | 要点覆盖、压缩、连贯 |
| 指导性写作 | 1 篇（120–150 词） | 25 | 24 分钟 | 要点、结构、语言 |
| **合计** | **78 题** | **150** | **120 分钟** | |

专项模式的题量与分值会相应缩减，见 `src/sections.ts`。

## 组卷逻辑

`src/lib/exam.ts` 中的 `generatePaper` 是纯函数，输入 `mode`、`section`、`difficulty`、`seed`、`seenIds`，输出完整 `Paper`：

1. 按板块配额从题库抽取素材。
2. 优先过滤掉 `seenIds` 中的题（最近做过的题）；该板块未做内容不足时，按“最久未见”优先补足，并把复用的题标注为“复习题”。
3. 难度为“基础/进阶”时，优先抽对应难度，再按难度距离补足。
4. 对每道选择题重新洗牌选项，并同步更新正确答案下标。
5. 选词填空从 10 个正确答案 + 1 个多余干扰词生成词库；干扰词取自未选中题目的 distractor，且不会与题库任何答案重复。
6. 为每道题分配全局题号，汇总板块分值、建议用时和上下文材料。

相同 `seed` 会生成完全相同的试卷，便于复现和测试；首页可手动输入种子，成绩单可用“按此种子重新组卷”复现原卷（组卷用的 `difficulty` 会保存在 `Paper` 上，回放时一并沿用）。

## 评分模型

- **客观题**（听力、语法单选、词汇、完形、阅读）：标准答案精确匹配。语法填空会忽略大小写、首尾标点和多余空格，并支持 `accept` 备选答案。
- **翻译（3 分/句）**：每句 3 个关键信息点，按正则匹配覆盖数给分；未作答为 0 分。答案词数明显偏离参考译文、缺少 ≥6 词的主谓从句，或要点全部挤在同一个 ≤5 词窗口内时，覆盖项封顶且不超过 1 分，并标注“低置信度初评”。
- **概要（10 分）**：
  - 要点覆盖 6 分（5 个要点按比例）；超过词数上限 1.25 倍、低于下限一半、没有完整句子，或整篇是要点清单（少于 2 句、单句超长、要点只落在同一句）时封顶 2 分；整段照抄原文时覆盖项减半；
  - 词数 2 分（50–80 词满分，偏离越多扣分）；
  - 连贯与压缩 2 分（句数、连接词、是否连续照抄原文 8 词以上）。
- **写作（25 分）**：
  - 内容要点 10 分（按任务要点覆盖率；少于 80 词时内容项最多 2 分，无完整句子同样封顶）；
  - 语言 8 分（词数、句长变化、词汇多样性、拼写/标点特征）；
  - 结构 7 分（段落、连接词、首尾完整度）。
- **达标标记**：主观题只给估分、不写 `correct`，也不参与评级；评级只看客观题。自动估分上限为题目分数的 90%，低置信度作答再按 50% 封顶；最终以人工阅卷为准。
- **建议引擎**：按考点得分率、板块失分与用时情况生成行动建议；主观题低于 70% 时不会输出“冲击高分”，并按失分多少为高分值板块保留建议位。最多保留 2 条“优先补”，避免一次给出过多任务。

规则评分只能作为练习反馈。真实考试中，翻译与写作由人工按评分细则阅卷。

## 数据与隐私

- 无后端、无账号、无网络请求（听力语音由浏览器本地合成）。
- `localStorage` 键：
  - `sh-exam.attempts.v1`：最近 20 次成绩与完整试卷快照；
  - `sh-exam.active.v1`：未交卷的考试草稿（含分板块计时与最后活跃时间）；
  - `sh-exam.seen.v1`：最近做过的题目 ID（用于避重）；
  - `sh-exam.settings.v1`：语速等设置。
- 浏览器存储写入失败时，交卷页会保留草稿并提供 JSON 备份下载/重试，不会清空进度后静默丢卷。
- 清理浏览器站点数据会删除全部记录。成绩单可通过浏览器打印/另存为 PDF。

## 扩展题库

1. 在 `src/data/` 对应文件中新增条目，保持 `id` 唯一。
2. 选择题确保 `answer` 是 `options` 中正确项的下标；解析不要引用选项字母（选项会被打乱）。
3. 中译英提供 3 个 `keyPoints`，每个包含若干可匹配的 `patterns`（正则片段）。
4. 概要/写作提供 5 个左右 `keyPoints`、参考范文与词数范围。
5. 运行 `npm test`，题库完整性测试会检查 ID、选项、答案下标、完形空号与主观题元数据。

## 已知限制

- 听力依赖浏览器语音合成，音色与可用性因浏览器/系统而异；不支持时会提示查看原文。
- 翻译/概要/写作的规则评分对“同义表达”的识别有限，可能出现漏判；建议结合参考译文、范文和评分细则自评。
- 题库为原创/改编练习材料，不对应任何官方真题。
- 单次成绩与建议只反映当前试卷，不能直接推断正式考试分数。
